# Automate the BS

Small, private tools that remove busywork. Built to run without accounts, uploads, or a server.

## ResumeRadar

A free, client-side ATS resume checker. Paste a resume and a real job posting to get a 0–100 match score, the missing keywords, parser warnings, and the fixes that matter first. No signup, no upload — the resume never leaves the browser.

- **Try it:** https://automatethebs.github.io/resume-radar/
- **Source:** https://github.com/automatethebs/resume-radar
- **Guides:** 39 role keyword guides, ATS formatting, tailoring, action verbs, and free templates
- **Pro report:** $9 one-time, paid in USDC on Base or with the demo code when no rail is configured

## Why these tools are different

- Deterministic scoring you can inspect and test, not a random "AI score"
- Privacy by architecture: no upload endpoint exists
- Static hosting, so there is no database to leak and no per-scan cost
